# Contributing

- To report a problem, fill in the [bug report form](https://github.com/jinzhuoli0908/arabesque/issues/new?template=bug_report.yml).
- To ask for another language or keyboard, fill in the [language request form](https://github.com/jinzhuoli0908/arabesque/issues/new?template=language_request.yml).
- The v1 rules in [docs/RULES.md](docs/RULES.md) are frozen.
- Pull requests that add network access, keystroke logging or third-party dependencies are not accepted.
- Run `scripts/test.sh` before you open a pull request.
